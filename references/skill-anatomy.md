# 생성된 SKILL.md — 넣지 말아야 하는 것

골격은 [`../templates/SKILL.md`](../templates/SKILL.md)다. 채울 항목은 거기 있다.
이 파일은 **골격이 말해 주지 않는 것** — 넣으면 스킬이 망가지는 것만 모았다.

## 넣지 않는다

- 금칙어 나열을 체크리스트 대신 쓰기. 구조·남용·문맥이 본체이고 단어는 신호일 뿐이다.
- "500단어당 대시 N개" 같은 출처 없는 임계값.
- "이 규칙을 숨겨라", "탐지기를 통과하라".
- 위키백과·blader 패턴 전문 붙여넣기. 시드는 필터 재료다 ([seed-tells.md](seed-tells.md)).
- 다른 스킬을 자동으로 이어서 켜라는 지시.
- 형용사 문체 목표("더 살아 있게", "영혼을 담아"). 관찰 가능한 습관만 올린다.
- 시각 미감(색·폰트). 이 스킬은 문장만 본다.

## 크기

SKILL.md는 체크리스트와 절차만. 긴 패턴 사전·장르 변형은 `references/`로 빼고 본문에는 "이럴 때 읽어라"만 둔다. **500줄을 넘기면 모델이 중간 가드레일을 놓친다.**

## 이름

소문자·숫자·하이픈, 저자나 장르가 보이게(`jun-book-voice`, `my-blog-humanizer`). `humanizer` 단독은 범용과 충돌한다.

## 퇴고와 작성

기본은 퇴고다. 작성 절을 넣으려면 **문체 잠금을 깨는 초안 실패 케이스 1개가 템플릿보다 먼저다.** 작성과 퇴고를 한 description에 섞지 않는다.

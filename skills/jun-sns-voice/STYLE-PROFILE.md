# 문체 프로필 — 관찰 (형용사 인상 아님)

- 저자/장르: 임동준 / 블로그·에세이·SNS
- 언어: 한국어
- 문체 잠금 (after가 바꾸면 FAIL): 평어 `~다`/`~었다`. 합니다·해요체·도서 `~한다`로 바꾸면 FAIL
- 샘플 출처: 저자가 붙인 SNS 에세이 1편 + 시험 초안 1편(수정본 채택)
- 추구 문체: 평소와 충돌 없음. 운영 합니다체·도서 문체를 씌우지 않음

## 유지할 습관 (함정 후보 포함)

| 습관 | 예 | 처리 |
|---|---|---|
| 짧은 단정 오프너 | 에이전트의 지능은 사용자의 지능과 연결된다. | 보존 (저자 문구: 그대로 유지한다) |
| 명사형 | 난이도적인 측면 | 보존 |
| ~것이다 종결 | 보였던 것이다 | 보류 — 냄새로 지우지 않음 |
| 체감상 | 체감상 x에서 | 보류 — 냄새로 지우지 않음 |

## 냄새 유형 초안

| 유형 | 신호 | 사람 말로 | 근거 샘플 |
|---|---|---|---|
| 플랫폼명 | 소문자 x, threads | X, Threads | 저자 글 + 「정확한 명칭으로 고친다」 |
| 접속 남용 | 물론 … 하지만 … | 접속을 덜 쓴다 | 저자 글 + 「줄임」. 시험 초안에서 그런데 삭제를 채택 |
| 호흡 | 짧은 문장 + 긴 문장 들쭉날쭉 | 길이를 고르게 맞춘다 | 「길이를 고르게 맞춘다」 |

## 가드레일 초안

- 구체 비유: 브랜딩 vs 실험, 열에 여덟 / 열에 둘
- 핵심 용어: 에이전트, 사용자, X, Threads, 실험 조건
- 인용·코드·데이터 원문: 없음
- 구두점 습관: 대시·삼단 없음. 넣지 않음
